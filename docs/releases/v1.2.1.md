# RTX HDR Image Studio v1.2.1

A maintenance release with security, stability, and performance fixes from two code audits on 2026-11-02.

## Highlights

- **Safer input decoding.** Files are only identified as PNG, JPEG, WebP, BMP, or TIFF, so a renamed EPS, PSD, FITS, or PDF file is rejected instead of reaching Ghostscript or another high-risk decoder. Pillow is upgraded to **12.3.0** for published PSD and FITS vulnerabilities.
- **Correct 16-bit grayscale.** Unsigned 16-bit grayscale PNG and TIFF images are scaled from their full range instead of being clipped to white. Unsupported signed-integer and floating-point images are rejected with a clear message.
- **Crash-isolated, interruptible previews.** Source images are decoded in helper processes. A decoder crash shows an error instead of closing the application; closing the window stops large decodes immediately.
- **No more growing cache.** Preview and job caches are deleted when no longer needed and on exit; crash leftovers are removed after 24 hours. Caches owned by another running instance are retained even after a day of inactivity. Cancelled exports no longer leave `.rtx-hdr-*` files in the output folder.
- **Smoother HDR comparison.** Dragging the divider in native HDR is now a GPU-side copy instead of a full-frame CPU copy and upload.
- **HDR recovers after a driver reset** without restarting the application.
- **Clearer GPU errors** that keep the original NVIDIA message and file name.
- Faster input preparation and preview linearization with exact lookup tables, and two fewer full passes over very large images during processing.

## Downloads

- **`rtx-hdr-image-studio-1.2.1-source.zip`**: tracked source, documentation, tests, and license.
- **`rtx_hdr_image_studio-1.2.1.tar.gz`**: Python source distribution.
- **`rtx_hdr_image_studio-1.2.1-py3-none-any.whl`**: Python wheel; this is not a standalone executable. The application requires Windows 11 x64 and Python 3.12.
- **`SHA256SUMS.txt`**: SHA-256 checksums for the three packages.

Dependencies remain a manual installation. Re-run `python -m pip install ".[gpu]"` to pick up Pillow 12.3.0. Python, CUDA and proprietary NVIDIA libraries are not bundled. See the [README installation instructions](https://github.com/TeddyWEinzbern/rtx-hdr-image-studio#manual-installation) and [third-party terms](https://github.com/TeddyWEinzbern/rtx-hdr-image-studio/blob/main/THIRD_PARTY.md).

## Validation

See [testing evidence](https://github.com/TeddyWEinzbern/rtx-hdr-image-studio/blob/main/docs/testing.md#version-121-validation-2026-11-02). New tests cover the decoder allow-list, 16-bit grayscale mapping, helper-process crash/interrupt/exit behavior, cache and staging-file ownership, byte-identical lookup tables, GPU composition against the previous CPU frame, and device-loss recovery.

Windows release validation passed **215 CPU/UI tests**, **5 real NVIDIA tests**, and **4 native tests**, using real Qt and JPEG XR dependencies. Ruff checks and isolated wheel/source builds passed. Native checks include full-screen HDR behavior, exact GPU composition readback, and device-loss fault injection; they do not establish physical HDR appearance or replace a real driver-reset test.
