# RTX HDR Image Studio v1.0.0

First public release of the independently rebuilt English application, licensed under MIT.

## Highlights

- NVIDIA TrueHDR processing for SDR still images with configurable luminance, contrast, saturation, middle gray, debanding, exposure, and GPU index.
- Native Windows Direct3D 11 HDR preview, split comparison, and SDR fallback.
- Full-resolution FP16 linear scRGB JPEG XR export with exact decoded-pixel verification.
- EXIF/ICC input handling, alpha compositing, JSON presets, batch processing, cancellation, and collision-safe output names.
- Separate processing, export, native display, and UI modules with CPU, GPU, and native tests.

## Downloads and installation

- **`rtx-hdr-image-studio-1.0.0-source.zip`**: complete tracked source, documentation, tests, and license. Recommended for following the README's manual installation instructions.
- **`rtx_hdr_image_studio-1.0.0.tar.gz`**: Python source distribution.
- **`rtx_hdr_image_studio-1.0.0-py3-none-any.whl`**: Python wheel. This is not a standalone executable. The generic wheel tag describes the Python package, not cross-platform desktop support; the application requires Windows 11 x64 and Python 3.12.
- **`SHA256SUMS.txt`**: checksums for the three attached packages.

No automatic installer, bundled Python, CUDA runtime, NVIDIA SDK binary, or user artwork is included. Install dependencies yourself using the [README](https://github.com/TeddyWEinzbern/rtx-hdr-image-studio#manual-installation).

For the wheel, after manually creating a Python 3.12 virtual environment, run the following from the download directory:

```powershell
.\.venv\Scripts\python.exe -m pip install ".\rtx_hdr_image_studio-1.0.0-py3-none-any.whl[gpu]"
.\.venv\Scripts\pythonw.exe -m rtx_hdr_studio
```

## Hardware and validation

NVIDIA RTX hardware supported by the VFX TrueHDR SDK and a CUDA 13-compatible driver are required for processing. Native HDR viewing additionally requires an HDR-capable screen with Windows HDR enabled. Full requirements and third-party terms are documented in README and THIRD_PARTY.md.

Local validation passed 28 CPU/UI tests, one actual NVIDIA worker preview/export test, and one native Direct3D FP16 GPU readback test. NVIDIA testing used an RTX 3070 Ti Laptop GPU with 8 GB VRAM and driver 621.01. The release workflow repeats CPU tests, lint, formatting, and package builds; GitHub-hosted CI does not verify real GPU inference or physical HDR appearance.

## Known limitations

Windows may lose HDR when scaling or cropping a wallpaper. Prepare suitable source dimensions yourself; the application deliberately preserves dimensions and does not manage wallpaper sizing or display settings. Correct JXR decoding does not guarantee that every viewer or Windows wallpaper path preserves HDR.

This is an SDR enhancement tool, not a color-faithful P3 container converter. Other hardware configurations remain subject to upstream SDK/driver compatibility.
